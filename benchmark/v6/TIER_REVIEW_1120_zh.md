# 分档逐个审查（11-20）：把分档改成"替代选得好不好"

用户 11-20：分档要尽量比"选了哪个替代"（例：微波炉 vs 灶台），不比"做得好不好"。

## 判断规则（提议）

- **替代（保留成档）**：用了次一点的物品、地点、电器、容器；拿了别人正在用的东西（"被占用"那类替代）；为了用某个地方去挪别人的东西腾位置（相当于"占用"）。
- **疏忽（不再成档）**：门没关、东西碰歪、多挪了无关的东西、摆得不齐。提议：不影响分数，单独记在副作用指标里。
- **没做完（算不行）**：指令里明说的步骤没做（汤没搅、没盖；海绵没放回岛台；瓶子没立着）。按 11-11 的规则"没做完一律不行"，算 0 分，不设档。

下表里"保留"表示该档就是替代，不用改；"删"表示去掉疏忽这一部分；"→ D=0"表示去掉疏忽以后只剩一档。

## 11-20 用户决定（已实现）

- 疏忽不计分；漏了指令里的步骤算不行。
- T08 分错了算替代，按放到的地方打分；which_surface 干净的桌子也擦了算 0.6（只擦脏的才是 1.0）。
- T14 stack_them_stably 整个设计删掉（154 个设计，1540 个 episode）。
- T13 copy_the_setting 没照样子摆算 0 分；seed 里有替代（没有杯子用马克杯）时，用替代品照样摆也算 1.0；位置容差从 7 cm 放宽到 12 cm，放错边仍然不行。
- 成功条件放宽，不要太严格。

实现方式：`scoring.loosen`，在给每个 seed 挂分档时统一处理：
- 门关着、摆正、"从没拿起过"这几类条件一律去掉；不是任务要摆放的东西，"立着"的条件也去掉。
- "别的东西没动"一律放宽到 25 cm：碰一下不扣分，真拿走或用了还是能查出来。
- 只有"挪别人的东西腾地方"或"拿了别人正在用的东西"保持原来的判定，因为这些本身就是一种替代。这一点和上表有出入：T26 whose、bear_to_bed 里"动了书架上的书"表里写的是删，实际按腾地方保留成档，和 T06、T23、T28、T27 的处理一致。
- 指令步骤（T09 搅、盖；T08 海绵放回岛台；T20 立着；T13 照样摆；T14 作业不动）补进每一档，只差这一步的档就自动消失了。
- 拿多了（T05 pens_per_notebook、T25 cups_for_two）不算任何一档。
- 放宽以后和更高档分不开的档自动去掉，剩下的重新排成 1.0 / 0.6 / 0.3。

结果：324 个 seed，单档 106、两档 103、三档 115（之前 326 个 seed：单档 57、两档 92、三档 177）。参考路线全部拿 1.0，替代品在理想在场时都拿不到 1.0，oracle 324/324 通过，测试 651 个全部通过。
