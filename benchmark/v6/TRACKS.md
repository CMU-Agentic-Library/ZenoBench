# ZenoBench v6 evaluation tracks

Generated by `python benchmark/v6/tracks.py` from `tasks.json` (`v6_tracks` per task, `tracks` at the top).  Two top-level categories; subcategories say what an episode tests.  Static only: physics status per family is in `PHYSICS_TODO.md`.

## Action-Level (`action`)

* Measures: local recovery from transient action failures and blocked actions (retry, re-approach, expose / separate, re-grasp, then the same call) with physical skills and limited observation.
* Runs with: planner `scripted`, profile `benchmark`.
* Owner: skill layer (scripted recovery routes); not scored for task planners.
* 99 families, 990 episodes (seeds 10-19).

## Task-Level (`task`)

* Measures: goal-preserving task-level replanning (DR, GD, SR, CL, PP, task-level alternatives) on GT skills, so execution noise does not decide the episode.
* Runs with: planner `any task planner (fixed, retry, VLM, ours); oracle route for validation`, profile `sticky_snap/gt`.
* Owner: task planners.
* 151 families, 1510 episodes (seeds 10-19).
