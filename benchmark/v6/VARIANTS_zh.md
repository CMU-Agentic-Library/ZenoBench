# ZenoBench v6 全部 variant 说明（127 个）

一局 = **任务 + variant + seed**。

- **variant**：这道题的设计。说明遇到什么情况、机器人要用什么 fallback 完成任务。
- **seed**（10–19，每个 variant 10 个）：只改布局，同一个 variant 的 fallback 和思路不变。布局由 seed 生成器（`layout.py`）抽取：
  - 物体在原来的桌面或柜面上随机重新摆放。挨着的、叠着的整组一起动，探出边缘的保持探出，不会放到比原来更靠里、够不着的地方，避开路线和事件要放东西的位置；柜子里、灶台上的不动。
  - 这个 variant 为了出题特意摆的东西（比对照组多摆的或摆法不同的，以及离它 15 cm 以内的东西）整组一起动，或者整组不动，比如摆满的餐桌、被围住的勺子、挡在擀面杖滚动路径上的碗。所以 seed 不会改变 variant 要测的东西。
  - 机器人在规定的房间里随机选一个能走到的位置，朝向也随机。需要搜索的题，开局看不到目标。
  - 带"seed 选择"的 variant，还要选用哪种摆法（见表格最后一列）。
  - 全部 1,270 局里，物体位移的中位数是 21 cm（90% 的局在 86 cm 以内），起点位移的中位数是 3.8 m（90% 的局在 8.4 m 以内）。

类别：

| 记号 | 类别 | 含义 |
|---|---|---|
| 对照 | Control | 没有挑战，原计划直接能成 |
| A | Action-Level | 短距离：在原地发现要多做什么，补上就能接着完成（推出、拨开、揭盖、挪开挡着的东西、开门；中途有人在原地动了东西，比如把书推回去、把番茄拿出来、把门又打开，原地恢复也算） |
| T | Task-Level | 长距离、要改计划：换东西、去别处找、分开放、换地方或器具、东西被拿到别处要去找 |
| A+T | 两者都有 | |

数量：对照 20、A 28、T 64、A+T 15，共 1,270 局。所有挑战都来自场景本身或中途有人动了东西；没有任何人为注入的动作失败（IK 拒绝、抓不住、滑落、放不准），无论一次还是每次。variant 名字沿用旧的（`h_action_`、`x6_cl_` 等前缀是历史命名，和现在的类别无关）。

## T01 把书拿到餐桌

|---|---|---|---|

| no_overhang | A | 书只探出 1.5 cm，夹不住 → 先把书推出边缘再抓 | |
| table_seats | T | 指令要求把书放在某位客人吃饭的位置旁边、和餐具留出空隙，但没说是哪个空位。餐桌东侧摆了三人份早餐（每个座位一个盘子或碗加一个杯子，另有两盒麦片），桌边有好几个空位：两套餐具之间的窄缝（放得下但会挨着餐具）、两盒麦片之间或桌子尽头的大空地（离座位远），还有一个座位旁边够宽的空位 → 看清桌面，自己判断哪个空位既在客人座位旁边、又放得下、和餐具留得出空隙，放在那里 | 三种摆法之一（合适的空位分别在第 2、3 座之间，第 1、2 座之间，桌子北端第 3 座旁）；餐具整排不动，seed 只改摆法、书在岛台上的位置和起点 |
| seat_slot_blocked | A+T | 摆法同 table_seats（第一种），但座位旁那个宽空位中间放着一盒麦片，桌上没有合适的空位 → 先把书暂放在桌子南端，把麦片往桌子里面挪，再把书放进座位旁的空位 | |
| which_table | A+T | 书平放在岛台上没探出边缘；家里有两张餐桌（近的在隔壁餐厅约 6 m，远的在西边另一间餐厅约 16 m），早餐只摆在其中一张上（三人份，和 table_seats 一样只有一个座位旁的合适空位），另一张上是孩子的积木和储物箱，桌边也有空位；指令只说放到客人吃饭的那张桌子上 → 原地把书推出边缘抓起，先到近桌看，没摆早餐就改去另一间餐厅，在摆了早餐的桌子上选座位旁的空位放下；放到另一张桌子上算失败 | 四种之一：近桌摆法 a / b，远桌摆法 a / b；两张桌上的东西不随 seed 动 |
| x6_dr_block_on_book__block | A | 书上压着积木 → 先拿开积木放在岛台上，再拿书 | |
| x6_dr_block_on_book__sponge | A | 书上压着海绵 → 先拿开海绵，再拿书 | |
