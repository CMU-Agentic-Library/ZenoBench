# v6 打分设计（逐个 design 讨论记录）

从 2026-11-11 开始。一个任务可以有多种完成方式，选不同的路线得分不同。

- **D**：任务有分岔（有不止一种可接受的完成方式，而且得分不同）时为 1，否则为 0。D = 0 就是没有 substitution，只有一个答案。
- **档位**：好的（1.0）、次好的、最不好的；有的只有好的和不好的两档。达不到任何一档的，即“压根不行”，记 0 分。
- 代码在 `benchmark/v6/scoring.py`（`SCORING` 表）。`define_tasks_v6.py` 把它写进 `tasks.json` 每个布局的 `scoring` 字段；episode 结束时按最终状态从最好的一档往下判，结果写进 `report["score"]`，日志里打一行 `SCORE`。分数的具体数值等全部讨论完再统一定。

## T01 book_to_dining_table（把岛台上的书拿到餐桌）

### overhang_ready（对照）：D = 0

- 书已经伸出岛台边缘约 6 cm，直接拿就行，拿书没有分岔。
- 两张餐桌都是餐桌，都符合指令。近的那张只是少走路，这已经由效率指标 SPL-c 衡量了，不再重复扣分。
- 好：书在任意一张餐桌上，手是空的。
- 不行：书在别处（茶几、岛台、台面、地上），或者还拿在手里。
