# v6 打分设计（逐个 design 讨论记录）

从 2026-11-11 开始。一个任务可以有多种完成方式，选不同的路线得分不同。

- **D**：任务有分岔（有不止一种可接受的完成方式，而且得分不同）时为 1，否则为 0。D = 0 就是没有 substitution，只有一个答案。
- **档位**：好的（1.0）、次好的（0.6）、最不好的（0.3），最多三档；两档时是“好 + 最不好”，或“好 + 次好”（低的那档只是小疏忽，如门没关，T07 起）。达不到任何一档的，即“压根不行”，记 0 分。
- 任务没做完（比如要三层只叠了两层、要找齐的东西没找齐）一律算“不行”，不设档（11-11 用户确认）。
- 好、次好、最不好**都算任务成功**（`task_success`），只是分数不同；“不行”算失败（11-11 用户确认）。
- 代码在 `benchmark/v6/scoring.py`（`SCORING` 表）。`define_tasks_v6.py` 把它写进 `tasks.json` 每个布局的 `scoring` 字段；episode 结束时按最终状态从最好的一档往下判，结果写进 `report["score"]`，日志里打一行 `SCORE`。分数的具体数值等全部讨论完再统一定。

## T01 book_to_dining_table（把岛台上的书拿到餐桌）

### overhang_ready（对照）：D = 0

- 书已经伸出岛台边缘约 6 cm，直接拿就行，拿书没有分岔。
- 两张餐桌都是餐桌，都符合指令。近的那张只是少走路，这已经由效率指标 SPL-c 衡量了，不再重复扣分。
- 好：书在任意一张餐桌上，手是空的。
- 不行：书在别处（茶几、岛台、台面、地上），或者还拿在手里。

### table_seats：D = 1

- dining_table_2 东侧摆了三个座位的早餐。东侧空位有三种：两个座位之间的窄空位、最远端的宽空位（不挨任何座位）、紧挨座位的宽空位；西半边全空。`_flat` 布局里要先把书推出岛台边缘，这是必经的一步，不算分岔。
- 好（1.0）：紧挨座位的宽空位，离餐具 ≥ 5 cm，什么都没动（即该布局的 goal）。
- 次好（0.6）：在这张桌上，离餐具 ≥ 5 cm，什么都没动，但不挨着座位（最远端或西半边）。
- 最不好（0.3）：硬塞进窄空位、贴着餐具，但没挪也没碰倒任何东西。
- 不行：放到另一张没摆早餐的餐桌（dining_table_1）；为腾地方挪了或碰倒了餐具；放在别处或还拿在手里。
- 11-11 用户决定：另一张餐桌算“不行”，硬塞算“最不好”（我原先的提议正好相反）。

### which_table：D = 1

- 两张餐桌，早餐摆在其中一张（seed 决定近桌或远桌），另一张放着玩具。指令不说哪张，要自己找到客人的桌子。
- 好 / 次好 / 最不好：在客人的桌上，分档同 table_seats。
- 不行：放到玩具那张桌（找错桌）；挪了或碰倒餐具；放在别处或还拿在手里。

### no_room_fallback：D = 1（分档随布局变）

- 指令给了兜底：“实在没合适的位置，就先收进书柜”。seats_b / seats_c 有紧挨座位的宽空位；full_a 的那个空位被麦片占了，但最远端和西半边仍空。四个书柜、任意一层都算，不分好坏。
- 有空位的布局：好 = 紧挨座位的空位；次好 = 桌上离餐具 ≥ 5 cm、不挨座位；最不好 = 硬塞贴着餐具，或者明明有空位却收进书柜（放弃得太早）。
- 没空位的布局（full_a）：好 = 收进书柜；次好 = 桌上离餐具 ≥ 5 cm、不挨座位（没照兜底做，但没影响用餐）；最不好 = 挤在座位旁贴着餐具或麦片。
- 不行：挪了或碰倒餐具、麦片腾地方；放在别处或还拿在手里。

### reader_seat：D = 1

- 三个座位旁都有宽空位，只有一个座位是带把手的马克杯（seed 决定是哪个）。要认出马克杯，把书放在那个座位旁。
- 好：紧挨马克杯座位，离餐具 ≥ 5 cm，什么都没动。
- 次好：桌上离餐具 ≥ 5 cm、什么都没动，但不挨任何座位（中性位置）。
- 最不好：桌上什么都没动，但放在别的客人旁边（认错人），或贴着餐具。
- 不行：挪了或碰倒餐具；放在别处（包括另一张餐桌）或还拿在手里。

### which_book：D = 1（两档）

- 三本书：岛台上一本（最显眼）、客人那本（在指令说的房间：客厅电视柜或卧室书柜）、另一个房间一本。
- 好：只把客人那本拿到任意一张餐桌，另两本没动。
- 最不好：客人那本到了餐桌，但另外的书也被拿来或挪了。
- 不行：客人那本没到餐桌（拿错或没拿）；还拿在手里。

## T02 stack_blocks（把一块积木叠到另一块上）

### clear（对照）：D = 0

- 两块积木在岛台上，周围空。谁叠谁都一样。
- 好：一块叠在另一块上，手是空的。不行：没叠上或积木掉了。

### crowded_use_another：D = 1（两档）

- tight 布局里积木 B 离满碗燕麦和擀面杖 3 mm，指令说别碰碗周围的东西；另一个房间（电视柜或餐桌）还有一块积木。loose 布局里 B 是松的。
- 好：tight 布局用 A 和别处那块叠（谁叠谁都行），B、碗、擀面杖都没动；loose 布局任意两块叠，碗和擀面杖没动。
- 最不好：tight 布局硬把 B 抽出来叠了，但碗和擀面杖没动、碗没倒。
- 不行：碗或擀面杖动了、碗倒了；没叠上。

### third_toy_elsewhere：D = 1（两档）

- 两块积木在岛台上，旁边一块积木大小的厨房海绵（不是玩具）；第三件玩具（鸭子或另一种积木）在别的房间。
- 好：三件玩具在岛台上叠成三层。
- 最不好：用海绵当第三层凑成三层。
- 不行：只叠了两层（没找到第三件）；没叠上；塔不在岛台上。
- 11-11 用户要求海绵也给分；之后又定只叠两层是没完成，算“不行”。

### tower_for_kid：D = 1

- 三块积木分散在家里（岛台、电视柜、另一个房间），在餐桌上叠成塔。餐桌上有收纳箱、两盒麦片和一把勺子。
- 11-11 用户决定：两张餐桌都算（goal 从只认 dining_table_2 改成 `on_any` 两张）。
- 好：三块叠在餐桌上，离桌边和桌上东西 ≥ 5 cm，什么都没动。
- 最不好：三块叠在餐桌上，什么都没动，但靠桌边或贴着收纳箱、麦片。
- 不行：只叠了两块（没找齐）；挪了桌上的东西；塔不在餐桌上；没叠上。

### tower_for_kid_duck：D = 1

- 只有两块积木（岛台，加电视柜或书桌），没有第三块，要用橡皮鸭当顶层（鸭子顶上不平，只能在最上面）。分档同 tower_for_kid。
- 好：两块积木加顶上的鸭子在餐桌上，离桌边和桌上东西 ≥ 5 cm，什么都没动。
- 最不好：三层塔在餐桌上，什么都没动，但靠桌边或贴着桌上东西。
- 不行：只叠了两层；挪了桌上的东西；塔不在餐桌上；没叠上。

### block_put_away：D = 1

- 两块积木在岛台上（A 在桌沿伸出 5 mm，不能当底座），第三块在两个关着的矮柜之一（cabinet 4 或 6）。指令要求找完把柜门关好。
- 好：三块叠在岛台上，底座离桌沿 ≥ 5 cm，两个柜门都关着。
- 次好：三块叠好、柜门都关了，但塔在桌沿（直接拿 A 当底座）。
- 最不好：三块叠好，但有柜门没关。
- 不行：只叠了两块（没找到第三块）；没叠上；积木掉了。

## T03 utensils_one_container（擀面杖和勺子收进同一个容器）

- 判定说明：`inside` 比较宽松（物体中心在容器口范围内、不高出口沿 3 cm）。擀面杖斜插进小箱子能判成“在里面”；整根横搭在箱口、中心太高的判不进去，只能算“不行”。

### large_only（对照）：D = 0

- 只有电视柜上的大收纳箱一个敞口容器。
- 好：两样都在大收纳箱里。不行：只收了一样；放进柜子、抽屉；还拿着或掉了。

### small_bin_or_bedroom_bin：D = 1

- 小收纳箱（里面两块积木）放得下勺子，放不下 22 cm 的擀面杖；大收纳箱在卧室书柜上。岛台上有马克杯。
- 好：两样都在大收纳箱里，小箱子里的积木没动。
- 次好：两样都在小箱子里（擀面杖斜插露在外面），积木还在小箱子里。
- 最不好：两样在同一个箱子里，但小箱子里的积木被拿出来或挪了。
- 不行：两样不在同一个容器；插进马克杯；只收了一样；把小箱子整个放进大箱子；还拿在手里。
- 11-11 用户决定：马克杯算“不行”；放小箱子算中间档；最多三档。

### which_bin_by_contents：D = 1

- 两个一模一样的大收纳箱，一个在电视柜、一个在卧室矮书架（哪个近由摆法决定）：玩具箱（`toy_storage_bin`）里是孩子的两块积木，厨房用具箱（`wide_storage_bin`）里是两把勺子。
- 好：两样都在厨房用具箱里，积木和勺子都没动（把厨房用具箱搬过来再放也算好）。
- 次好：两样都在厨房用具箱里，但积木或勺子被拿出来或挪到别的箱子。
- 最不好：两样都在玩具箱里（放错箱子、没往里看），什么都没动。
- 不行：放进玩具箱且动了里面的东西；两样分在两个箱子；只收了一样；还拿着或掉了。
- 11-11 用户决定：放错箱子但没弄乱算“最不好”。

### no_bin_substitute：D = 1

- 家里没有大收纳箱（马克杯也拿掉了）；替代品（卧室地上的储物篮或书房桌上的托盘，按摆法）在别的房间；电视柜上的小箱子（两块积木）放不下擀面杖、只能斜插；餐桌上的果篮装着苹果和橙子。
- 好：两样都在替代品里，水果和小箱子的积木都没动。
- 次好：两样都在替代品里，但动了水果或积木；或者两样都在小箱子里（擀面杖斜插），积木还在、水果没动。
- 最不好：两样都在小箱子里但积木拿出来了（或动了水果）；两样放进果篮（水果在里面，或先拿出来）。
- 不行：两样分在两个容器；只收了一样；放进柜子或抽屉；还拿着或掉了。
- 11-11 用户决定：果篮两种情况都算“最不好”。

### utensils_apart：D = 0

- 擀面杖在岛台，勺子落在另一个房间（餐桌或厨房台面，按摆法），一开始看不见；大收纳箱在卧室矮书架上，是唯一的敞口容器（马克杯拿掉了）。
- 好：两样都在大收纳箱里，手空着（先把箱子搬过去再放也算好）。
- 不行：只收了一样（勺子没找到）；放进柜子、抽屉或随手放桌上；还拿着或掉了。

## T04 cup_or_mug_to_cabinet（在靠墙矮柜上的饮品角摆一个杯子）

### cup_available（对照）：D = 0

- 岛台上并排一个玻璃杯和一个马克杯。
- 好：玻璃杯或马克杯立着放在矮柜（kitchen_cabinet_6）顶上，手空着；两个都放也算好。
- 不行：杯子倒着或躺着；放到别的柜子、台面或餐桌；还拿着或掉了。
- 11-11 用户决定：有玻璃杯时拿马克杯也算好（no_cup 专门考马克杯顶替）。

### no_cup：D = 0

- 家里没有玻璃杯；主马克杯在岛台（看得见）、电视柜或餐桌（看不见），按摆法；家里另有吊柜、架子、台面上的三个马克杯。
- 好：任意一个马克杯立着放在矮柜上，手空着（绕远的代价由 SPL 计）。
- 不行：拿果汁瓶等不是杯子的东西顶替；倒着或躺着；放到别处；没找到杯子；还拿着或掉了。

### clear_the_drinks_spot：D = 1

- 早餐后的燕麦粥碗和锅盖占满了矮柜饮品角（碗居中，两边各 8 cm，放不下杯子）；指令要收拾好再放杯子。
- 好：碗和锅盖都回到厨房（岛台、灶台、台面），碗立着，矮柜上立着一个杯子（玻璃杯或马克杯）。
- 最不好：碗和锅盖都离开了矮柜，但放在厨房外（餐桌、茶几、别的柜子），碗立着，杯子摆好。
- 不行：只拿走一样（硬塞杯子）；推到矮柜另一头；碗倒了；没放杯子或杯子倒着；还拿着或掉了。
- 11-11 用户决定：放在厨房外算“最不好”。冰箱、厨房柜子里面暂时不算厨房位置（落到最不好），待定。

### two_guests：D = 1

- 家里只有一个玻璃杯（岛台），主马克杯在餐桌或书房书桌（按摆法），另有三个马克杯；指令要两个杯子、别挨着。
- 好：两个杯子（玻璃杯加马克杯，或两个马克杯）立在矮柜上，相距 ≥ 3 cm。
- 最不好：两个杯子立在矮柜上，但贴在一起或相距不到 3 cm。
- 不行：只摆了一个（没找到第二个）；拿果汁瓶等当第二个；倒着或躺着；放到别处；还拿着或掉了。
- 11-11 用户决定：两个马克杯也算好（成功条件已改成任意两个）。

### x6_gd_cup_in_cabinets：D = 1

- 指令要不带把手的杯子，收在厨房矮柜里，用完关柜门；玻璃杯在关着的 cabinet 4 或 6（按摆法），岛台上马克杯一眼可见。
- 好：玻璃杯立在矮柜上，两个柜门都关着（多放个马克杯不扣分）。
- 次好：玻璃杯立在矮柜上，但有柜门没关。
- 最不好：拿马克杯（带把手）顶替，没去柜子里找。
- 不行：没摆杯子；杯子倒着或躺着；放到别处；还拿着或掉了。
- 11-11 用户决定：马克杯顶替算“最不好”；没关柜门问题不大，算“次好”。

## T05 pen_or_pencil_to_desk（孩子写作业要笔，拿到书房书桌上）

### e1_pencil_asked（对照）：D = 0

- 钢笔拿掉了，铅笔在卧室书架上；指令要铅笔。
- 好：铅笔在书房书桌上，手空着。
- 不行：铅笔放到别处；拿了别的东西当笔；还拿着或掉了。

### no_pen_pencil_away：D = 0

- 钢笔拿掉了，铅笔在另一个房间的餐桌上，一开始看不到；只是要找，没有替代。
- 好：铅笔在书房书桌上，手空着。
- 不行：没找到铅笔；放到别处；拿了别的东西当笔；还拿着或掉了。

### check_desk_first：D = 1

- 指令要钢笔；书桌上已有钢笔（看一眼就该停，铅笔在卧室书架）或只有铅笔（要去卧室拿钢笔），按摆法。
- 好：钢笔在书桌上，别的没动（钢笔已在就停；只有铅笔就把钢笔拿来、铅笔留原处）。
- 次好：钢笔在书桌上，但多动了东西（钢笔挪远、铅笔被拿走或挪开、把铅笔也拿来）。
- 最不好：书桌上没有钢笔，只有铅笔（看到铅笔就停了）。
- 不行：书桌上既没有钢笔也没有铅笔；还拿着或掉了。
- 11-11 用户决定：看到铅笔就停算“最不好”。

### all_pens：D = 0

- 指令要把家里所有钢笔和铅笔收到书桌，没说几支；2、3 或 4 支分散在卧室、餐厅、客厅、厨房（按摆法）。
- 好：所有笔都在书桌上，手空着（顺手多拿了别的东西不扣分）。
- 不行：漏了一支或几支；笔放到别处；还拿着或掉了。

### homework_ready：D = 1

- 指令只说写作业要用的东西；要一支笔加一本作业本，旁边有红书（不是作业本）和泰迪熊；single / several / pencil_only 三种摆法。
- 好：一支笔加一本作业本在书桌上，红书和泰迪熊没动（多拿笔和本子不扣分）。
- 次好：笔和本子都到了，但红书或泰迪熊也被拿来或挪动。
- 最不好：笔加红书（用红书顶替作业本）。
- 不行：只拿了笔或只拿了本子；拿泰迪熊等无关东西凑数；放到别处；还拿着或掉了。
- 11-11 用户决定：带上红书算“次好”。

### pens_per_notebook：D = 1

- 书桌上 2 或 3 本作业本（按摆法），指令要每本旁边一支笔、不要多拿；家里 4 支笔分散在卧室书架、电视柜、餐桌。
- 好：正好 N 支，每本作业本 15 cm 内一支，其余的笔没动。
- 次好：正好 N 支、其余没动，但没有每本旁边一支（堆在一起）。
- 最不好：拿多了（N+1 或 4 支全拿），摆没摆到本子旁边都算。
- 不行：拿少了；笔放到别处；还拿着或掉了。
- 11-11 用户决定：数对没摆好算“次好”，拿多了算“最不好”。

### errand_combined：D = 1

## T07 heat_oatmeal（把剩下的燕麦粥热一下当早饭，至少 40 度）

- 判定说明：粥在灶台上也能热（每秒 2 °C）。新增 episode/heat_log.py 记录每一步是哪个电器让粥升温（灶台开着且粥在灶眼上算灶台，否则算微波炉），判定条件 `heated_by` 读这个记录。

### microwave_works（对照）：D = 1

- 微波炉是好的，粥在适合进微波炉的瓷碗里。
- 好：只用微波炉热到 40 °C，灶台关着，微波炉门关着。
- 次好：用了灶台（全部或一部分）、最后关了火；或用微波炉但门没关。
- 最不好：用了灶台，微波炉门也没关。
- 不行：没到 40 °C；灶台没关火；碗打翻；还拿着或掉了。
- 11-11 用户决定：微波炉能用时上灶要扣分，算 0.6；灶台没关火算“不行”。用灶台扣分只在微波炉能用、容器也适合时。

### microwave_broken：D = 1

- 微波炉会转但不加热，只能用灶台（用灶台不扣分）；粥在岛台、矮柜或餐桌（按摆法）。
- 好：用灶台热到 40 °C，关了火，微波炉门关着。
- 次好（0.6）：灶台热好关了火，但试过微波炉后门没关。
- 不行：微波炉不热就放弃（没到 40 °C）；灶台没关火；碗打翻；还拿着或掉了。
- 11-11 用户决定：两档也可以是“好 + 次好（0.6）”，门没关统一 0.6。

### microwave_holds_pot：D = 1

- 微波炉里放着带盖的汤锅，粥碗放不进；两个灶眼空着。
- 好：把汤锅拿出来（台面或灶台）再用微波炉热；或汤锅不动直接用灶台热。到 40 °C，关火，微波炉门关着。
- 次好（0.6）：热好了，但微波炉门没关。
- 不行：汤锅放地上；没到 40 °C；灶台没关火；碗打翻；还拿着或掉了。
- 11-11 用户决定：微波炉被占着时上灶不扣分。

### vessel_decides_appliance：D = 1

- 容器决定电器（按摆法）：瓷碗、玻璃饭盒用微波炉；金属汤锅、不锈钢饭盒、锡纸盒用灶台；用错不升温。
- 判定说明：heat_log 另记每个容器在开着的电器里待了多久（不管升没升温），判定条件 `exposed_in` 读它；待满 1 秒算“用过”。
- 好：一开始就用对电器，到 40 °C，都关了，微波炉门关着。
- 次好：用对电器热好了，但微波炉门没关。
- 最不好：先用错电器（金属进了开着的微波炉，或瓷碗、玻璃盒上了点着的灶），再改对热好。
- 不行：用错热不起来就放弃（没到 40 °C）；电器没关；容器打翻；还拿着或掉了。

### two_portions：D = 1

- 粥（瓷碗，只能微波炉）和汤（金属锅，只能灶台，在餐桌或厨房台面），都要 ≥ 40 °C；食物每秒凉 0.2 °C。只看结束时的结果。
- 好：结束时两样都 ≥ 40 °C，一开始就各用对电器，都关了，门关着。
- 次好：两样都热好了，但微波炉门没关。
- 最不好：先把碗上灶或锅进微波炉试过，再改对。
- 不行：结束时有一样不到 40 °C；电器没关；打翻；还拿着或掉了。

- 最不好：漏了两样或三样。
- 不行：只放了两颗；没到 60 °C；灶台没关火；番茄掉出锅外；还拿着或掉了。

- 一颗番茄在岛台，另一颗在餐桌或矮柜（按摆法）。分档同对照组；只放了一颗算不行。

### T25_drink_for_guest（客人在客厅坐着，给他拿点喝的。）

- **drink_on_island**：D = 0。果汁和杯子在岛台（对照）。
  - 好：果汁和杯子（马克杯也行）到电视柜。
  - 不行：缺饮料或杯子；果汁躺着；还拿着或掉了。
- **cup_elsewhere**：D = 0。岛台只有果汁，杯子在小厨房台面。
  - 好：果汁和杯子到客人那。
  - 不行：缺饮料或杯子；果汁躺着；还拿着或掉了。
- **cold_one**：D = 1。天热；岛台一瓶常温的，冰箱里一瓶冰的。
  - 好：拿冰的和杯子，冰箱关好，常温的没动。
  - 次好：拿了冰的，但冰箱没关或也挪了常温那瓶。
  - 最不好：拿了常温那瓶。
  - 不行：缺饮料或杯子；躺着；还拿着或掉了。
- **drink_in_fridge**：D = 1。外面没饮料，果汁在冰箱。
  - 好：拿出果汁和杯子，冰箱关好。
  - 次好：拿了但冰箱没关。
  - 不行：缺饮料或杯子；躺着；还拿着或掉了。
- **cups_for_two**：D = 1。两位客人；客人那已有 0-2 个杯子，矮柜里 1-2 个；其他只有餐厅的马克杯；尽量用普通杯子、不重复拿。
  - 好：一共两个普通杯子（已有的不动、不多拿），柜门关好。
  - 次好：杯子对了，但柜门没关或挪了已有的杯子。
  - 最不好：够两个，但柜里有普通杯子却用了马克杯，或拿多了。
  - 不行：不到两个杯子；没饮料；躺着；还拿着或掉了。
- **two_guests**：D = 0。两位客人，一瓶果汁两个杯子在岛台。
  - 好：果汁和两个杯子到客人那。
  - 不行：只拿一个杯子；缺饮料；还拿着或掉了。
- **little_guest**：D = 1。客人是小朋友；岛台上瓷杯和塑料杯。
  - 好：果汁和塑料杯。
  - 次好：塑料杯和瓷杯都拿了。
  - 最不好：只拿了瓷杯。
  - 不行：缺饮料或杯子；躺着；还拿着或掉了。

### T27_leftovers_to_fridge（晚饭吃完了，把剩菜收进冰箱。）

### T30_bowls_for_soup（汤快好了，拿碗过来准备盛。）

- **bowl_on_cabinet**：D = 0。汤在灶上，干净碗在靠墙矮柜（对照）。
  - 好：碗拿到岛台。
  - 不行：岛台上没碗；碗掉了；还拿着。
- **how_many**：D = 0。餐桌摆了三把勺子，柜上三个干净碗。
  - 好：三个碗到岛台。
  - 不行：不到三个；碗掉了；还拿着。
- **bowls_in_cabinet**：D = 1。三把勺子；柜上一个碗和一个马克杯，柜里还有两个或一个碗；家里没别的碗。
  - 好：凑够三个（碗不够时才用马克杯），柜门关好。
  - 次好：凑够了但柜门没关。
  - 最不好：柜里还有碗却用了马克杯。
  - 不行：不到三个；掉了；还拿着。
- **bowl_put_away**：D = 1。外面没碗，干净碗在矮柜里。
  - 好：拿碗到岛台，柜门关好。
  - 次好：拿了但柜门没关。
  - 不行：岛台上没碗；碗掉了；还拿着。
- **no_bowl**：D = 1。家里没有干净碗，柜上一个马克杯一个盘子。
  - 好：拿马克杯（能盛汤的替代）。
  - 最不好：拿了盘子。
  - 不行：什么都没拿；掉了；还拿着。
- **bowl_not_plate**：D = 1。柜上一个碗旁边是盘子，或是一碗还盛着燕麦的碗。
  - 好：只拿干净的碗。
  - 次好：干净碗拿了，盘子或满碗也拿了。
  - 最不好：只拿了盘子或那碗满的。
  - 不行：什么都没拿；掉了；还拿着。
