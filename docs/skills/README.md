# 技能的执行步骤（3b 第 2 项之后，2026-11-04）

这组文档讲现在（`0c7eb90`）每个技能在物理上一步一步做什么：手臂、底盘、手指各走到哪里，每一段查不查碰撞，失败了会怎样。不讲代码怎么实现。为什么这样改、试过什么，见 `../COLLISION_PLAN.md` 第 9 节（试过、不要再做的）和对应的提交。

## 先读哪篇

1. **[接近与离开](approach_leave.md)**：所有改过的技能都用这两个动作走进接触、走出接触。读懂它，后面每个技能就只剩"给了什么方向、什么长度"。
2. **[pick](pick.md)**：捏取。
3. **[place](place.md)**：放到台面、浅容器、深容器、层板上。
4. **[drop 和 hover](drop_hover.md)**：在容器上方松手；举着东西悬停在目标上方。
5. **[wipe](wipe.md)**：拿海绵擦台面。
6. **[搬运姿态](carry.md)**：拿着东西时手臂放在哪里。pick 结束、导航出发前、放置和 drop 之前都会用到。
7. **[导航与收臂](navigate.md)**：navigate、navigate_place、收臂（右臂、左臂）。

## 这次改了什么

**直接改写了路径点的：** pick（捏取）、place、drop、wipe、navigate_place。

**改了共用部分、所以其他技能的行为也变了的：**

| 共用改动 | 物理上的效果 | 影响到谁 |
|---|---|---|
| 目标物体豁免按真实包围盒算 | 手要去的位置附近的物体，只有真的在它几厘米内才不当障碍物。以前扁平的大物体（托盘）会被放大成一个高 0.34 m 的方块，整个被当成"要碰的东西"，规划器看不见它 | 所有查碰撞的手臂运动 |
| 手里有东西时完全不做目标豁免 | 拿着东西去放、去倒、去悬停时，目的地的容器、托盘、锅都是障碍物 | 所有持物运动 |
| 搬运姿态的规划查手指 | 拿着东西挪到身前时，手指也不许擦过台面 | 拿着东西的 navigate、place、drop、hover、wipe、搅拌、倒 |
| 收臂可以选"下垂" | 收起姿态在当前位置会碰时，手臂改成垂在身侧 | 空手的 navigate、放完东西、开关门失败后、转身、wave 等 |
| 停车点能否开到，按整个场景算 | 要绕出起点附近范围才能到的站位，不再被误判为开不到 | navigate_place、search_object |

**结构没动的（还是旧的写死路径点，归 3b 其余或 3c）：** 平板物体的推到边再捏（`pick_flat`、corner / edge 捏取）、书的平放（`place_flat`）、push、开关门、倒、搅拌、翻书、扶正、微波炉、双手。它们会受上表的共用改动影响。

## 几个词

| 词 | 意思 |
|---|---|
| 中继位姿 | 技能必须到达的位姿：抓取位姿、物体放在支撑面上的位姿、松手位姿。它们之间怎么走由规划器决定 |
| 接触段 | 手（或手里的物体）已经贴着东西的那一小段，比如手指夹住物体前后、物体底面贴近支撑面时。这一段沿规定方向走直线，**不查碰撞**，长度由碰撞模型判断"什么时候不再碰"决定 |
| 自由段 | 接触段之外的运动，**查碰撞**，由规划器生成 |
| 查手指 | 手指算进碰撞模型。很多旧动作不查手指（`ignore_fingers`），手指可以穿过台面 |
| 目标豁免 | 手要去碰的那个物体不当障碍物 |
| fallback | 查碰撞的自由段规划不出来时，唯一的退路：从当前位置直线走过去（不查碰撞），并记一条 `clearance_fallback`。放进容器时没有这条退路，直接失败 |
| 停车点 | 底盘停的位置和朝向。技能先搜索停车点，验证在那里手臂能走完这个技能的所有中继位姿，再开过去 |
