# drop 和 hover

两者都是"把手里的物体举到某个东西正上方"，只有一个中继位姿；drop 到了就松手，hover 停在那里。它们共用同一个停车点搜索（`park_over`）：手里的物体按现在的握法挂在手上（`Motion.carrying`），手指查碰撞，不做目标豁免。

## drop（扔进容器）

`skills.drop_into`。`drop` 动作（`DropIntoPolicy`）和 `place(name, "in:<容器>")` 都走这里，托盘除外（托盘走 [place](place.md)）。不再按沿口高度分流。

**中继位姿：物体在容器开口上方，最低点比沿口高 `LEAVE_GAP`（5 mm）。** 不放下（在空中松手），也没有抽出段（物体落下后手指之间什么都没有）。

1. **已经在上面了吗？** 物体中心在开口中心 0.6 个半径以内，最低点在沿口以上 0–25 cm（比如先 hover 过来的）：直接跳到第 6 步松手。
2. **摆好搬运姿态**（见[搬运姿态](carry.md)），物体底部在沿口以上（`_carry_bottom_z`），之后按这个姿态找停车点。
3. **找停车点。** 目标集合：开口中心，以及从中心往 ±x、±y 各偏到物体还离得开内壁的位置（深的桶放在桌上，中心可能够不着），偏出去的代价高一点；每个点手腕绕竖直轴转 8 个角度，转得越多代价越高。每个位姿在停车点上要有 IK、查手指、容器是障碍物；能从搬运姿态带着倾角约束规划过去；手空了、张到抓取宽度以后，从那里能规划到收起或下垂；开得过去。
4. **开过去。**
5. **规划到松手位姿**（`drop_above`）：查手指，容器和周围物体都是障碍物，保持物体倾角。规划不出来就失败，没有 fallback。检查物体还在手里。
6. **松手**：40 帧内张开到抓取时的宽度，等 1 秒让物体落下。
7. **收臂到行驶姿态**（`Rig.tuck`）。
8. **检查**：物体要整个在容器里。

**已知问题：**

- 要露在容器外面的物体（擀面杖插进杯子）从沿口上方松手会倒或弹出去。以后按几何分流：整个落得进开口的 drop，露在外面的走放下段插进去（计划第 7 节）。
- T19 bin_on_bookcase ×2、T12 toys_everywhere s11：以前第 5 步保持倾角时 cuRobo 优化失败（6.2 重写前的记录，待复查）。

## hover（悬停在目标上方）

**中继位姿：物体底面居中、在目标顶面上方 6 cm**（目标是容器时，以沿口为顶面）。

1. **摆好搬运姿态。**
2. **找停车点**：和 drop 第 3 步一样（只有一个点），8 个手腕朝向，查手指。
3. **开过去。**
4. **规划到悬停位姿**（`hover_above`）：查手指，目标是障碍物（手里有东西时不做目标豁免），保持物体倾角；规划不出来就失败。
5. **检查物体还在手里**，停 30 帧。
