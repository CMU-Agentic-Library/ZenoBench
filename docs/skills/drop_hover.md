# drop 和 hover

两者都是"把手里的物体举到某个东西正上方"，只有一个中继位姿；drop 到了就松手，hover 停在那里。它们共用同一个停车点搜索（`park_over`）。

## drop（扔进容器）

**中继位姿：物体在容器沿口正上方 5 cm、居中**（最低点离沿口 5 cm）。

1. **已经在上面了吗？** 物体中心在开口中心 0.6 个半径以内，最低点在沿口以上 0–25 cm（比如先 hover 过来的）：直接跳到第 6 步松手。
2. **摆好搬运姿态**（见[搬运姿态](carry.md)），之后按这个姿态找停车点。
3. **找停车点。** 目标集合是：手腕绕"物体参考点的竖直线"转 8 个角度（0°、±45°、±90°、±135°、180°）的 8 个位姿，转得越多代价越高。每个位姿在停车点上要有 IK，查手指，容器是障碍物；能从搬运姿态带着倾角约束规划过去；开得过去。
4. **开过去。**
5. **规划到松手位姿**（`drop_above`）：查手指，容器和周围物体都是障碍物，保持物体倾角。规划不出来走 fallback（从搬运姿态直线过去，不查碰撞；计划 6.2 删）。检查物体还在手里。
6. **松手**：40 帧内张开到抓取时的宽度。
7. **离开接触**（`drop_retreat`）：竖直向上，直到手不碰任何东西。在空中松手，手本来就不碰，长度一般是 0，手停在原处。
8. **检查**：停 120 帧，物体要整个在容器里。

**已知问题：**

- T19 bin_on_bookcase ×2、T12 toys_everywhere s11：第 5 步保持倾角时 cuRobo 优化失败，规划不出来。
- 停车点验证不看松手后能不能收臂（计划 6.2）。

## hover（悬停在目标上方）

**中继位姿：物体底面居中、在目标顶面上方 6 cm**（目标是容器时，以沿口为顶面）。

1. **摆好搬运姿态。**
2. **找停车点**：和 drop 第 3 步一样，8 个手腕朝向，查手指。
3. **开过去。**
4. **规划到悬停位姿**（`hover_above`）：查手指，目标是障碍物（手里有东西时不做目标豁免），保持物体倾角；规划不出来走 fallback（计划 6.2 删）。
5. **检查物体还在手里**，停 30 帧。
