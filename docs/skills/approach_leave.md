# 接近与离开

技能里进出接触的直线怎么做。pick 和 place 用计划里的原语（`zeno_skills/primitives.py`，见 `../MOTION_ARCHITECTURE.md` 第 5 节），停车点搜索和执行是同一个函数，执行原样走搜索的路点；还没迁移的技能用 `Rig` 里的旧机制：

- **直线进入中继位姿**（`skill_plans._reach` + `primitives.straight`）：到直线起点，再从那一段实际停下的关节解走直线到中继位姿。pick 的伸入段、place 的放下段。
- **接触段**（`primitives.contact_extent` + `contact_segment`）：从接触里退到不碰为止的直线，长度由碰撞模型量。pick 的抬起段；place 的放下段长度也这样量。
- **撤手直线**（`primitives.straight`，`Spec.touch`）：place 的抽出段。
- 旧机制：**接近**（`Rig._approach`，`move_to` 带 `approach=`，wipe 的按压）；**离开**（`Rig.leave`，pick 抓空 / 被挡住时的 `pick_fail_clear`、开关门）。（`Rig.move_relay` + `rig.relay_approach` 11-08 已注释掉。）

技能只给中继位姿、方向和直线长度；直线从哪里开始、接触段多长，由碰撞模型算出来，不是技能里写死的点。

技能里的直线按物理过程叫，pick 和 place 互为倒序（计划第 2 节）：

| 物理过程 | pick | place |
|---|---|---|
| 手指进出物体 | 伸入段（`pick_grasp`）：直线进入抓取位姿，长 `pick_approach()` | 抽出段（`place_pull_out`）：撤手直线，长 `pick_approach()` |
| 物体进出支撑面 | 抬起段（`pick_lift`）：接触段，竖直向上 | 放下段（`place_down`）：直线进入放下位姿，长度按抬起段的量法量 |

## 直线进入中继位姿

技能给出：中继位姿 P（抓取位姿、放下位姿），方向 u，直线长度 L。整段查碰撞：手指在碰撞模型里，目标不豁免（要抓的物体、支撑面、邻物都是障碍物），手里有东西时它也在模型里。

1. 直线起点 S = P − L·u。手的 TCP 已经在这条直线上（离直线不到 `ON_LINE` 5 mm、还没走过 P）：没有自由段。
2. 否则自由段到 S（`primitives.free_leg`）：先试 TCP 直线；不通时——
   - 手里没东西：按位姿规划（末端沿 u 进入，`Kinematics.plan_to`），还不行就规划到关节目标（S 的一个解：搜索里是排序那次的运动学 IK 解，执行重做时是计划里 S 的解在实际底盘下沿原分支重解）；
   - 手里有东西：关节规划到 S 的解，倾斜超标或失败再保持倾角按位姿规划（`Kinematics.plan(carry=True)`）。
3. 直线从自由段**实际停下的关节解**出发走到 P，查碰撞（`primitives.straight`，路点间隔 `APPROACH_STEP` 3 mm）。不从 S 另求一个 IK 解：规划可能停在另一个分支上，从那里往下走手肘撞桌子（T20 bottle_on_cabinet）。
4. 哪一步做不出来就返回原因（`Failure`），搜索时不要这个停车点，执行时技能失败，不走 fallback。

## 接触段

技能给出：方向 u（pick 的抬起段竖直向上），"还在碰"的判据。不给终点。

1. 沿 u 求运动学直线，求到 IK 求得到的地方，最多 `LEAVE_MAX`（6 cm）。
2. 沿这条直线一步步往前查，机器人（含手指、手里的物体）什么时候离开周围所有东西 `LEAVE_GAP`（5 mm）以上，再多走 `LEAVE_MARGIN`（1 cm）就停（`primitives.exit_length`）。这一段不查碰撞，执行时允许手和手里的物体碰它们一开始就在碰的东西（`LEAVE_CONTACT`，`Rig._from_contact` 按当时的接触填）。
3. **抬起物体时多一条**（`off_support`）：手还没比起点高出 `LEAVE_GAP`，就算物体还在支撑面上。（11-11 前手里物体的碰撞球内切在包围盒里，底边差 5 mm 以上，平放时模型常常一开始就判成"不碰"，长度为 0 的抬起段接着横着走，会把物体拖在台面上；现在的碰撞球贴着物体表面，最多差 6 mm，这一条仍然保留。）
4. 到头（`LEAVE_MAX`，或 IK 走不到）还碰着就是 Failure——不缩短、不跳过（旧的 `Rig.leave` 会减半再试、最后不动）。
5. 执行前从当前姿态按实测状态重量一次，和计划的长度差超过 `EXTENT_TOL`（`LEAVE_MARGIN` 的一半），就从这里重做剩下的计划（`primitives.holds`）。

11-06 全量里 pick 抬起段中位数 1.7 cm、最长 4.0 cm。

**place 的放下段长度是抬起段倒过来量的**（`skill_plans.set_down_length`）：从抬起段会开始的地方（物体贴在支撑面上，放下位姿往下 `LEAVE_GAP`）竖直往上，用同样的判据（`off_support`）量到哪里算离开；放下位姿以上那一截就是放下段。

## 撤手直线

place 松手以后（计划里物体落下 `LEAVE_GAP` 成了障碍物，手张到抓取宽度），从放下段终点沿夹爪轴往回 `pick_approach()` 的一条查碰撞的直线。刚放下的物体在 `Spec.touch` 里：对手指不算障碍物（它可能靠到手指上：沿口捏的杯子转到杯里那根手指上，T13），手臂除手指外另外查不能碰它（`Motion.path_free_only`），其余东西照常查；监视器按 `Allow(touch=(物体,), links="fingers")` 把手指碰它记成允许的接触。11-08 起没有"先离开接触"那一截。

## 接近（旧机制，wipe 的按压）

`Rig._approach`（`move_to` 带 `approach=`，`into_contact`）：

1. **算出 P 处的手臂姿态。** 先找一个在 P 处不碰东西的姿态，用接触段自己的规则判断"不碰"：手指、手里的物体可以碰支撑面或容器，其余（夹爪本体、手腕、小臂、身体）都不许碰。找不到才用不查碰撞的姿态。
2. **从 P 沿 −u 往回量接触段**，看机器人什么时候不再碰任何东西，再多退 `LEAVE_MARGIN`，作为接触段的起点 C。最多退 `LEAVE_MAX`，还在碰就交给 fallback。
3. **自由段到 C**：规划到直线起点 S，再从 S 沿直线走到 C，查碰撞、查手指；规划不出来或直线会碰：fallback，从当前位置直线走到 C，不查碰撞，记 `clearance_fallback`。
4. **接触段：从 C 沿 u 直线走到 P，不查碰撞**，允许手、手里的物体碰声明过的东西。

## 碰撞规则汇总

| 段 | 查碰撞 | 手指 | 要抓 / 要放到的物体 | 做不出来 |
|---|---|---|---|---|
| pick 的到伸入段起点、伸入段 | 查 | 查（张到候选宽度） | 障碍物 | 搜索：不要这个停车点；执行：失败 |
| pick 的抬起段 | 不查（接触段） | 用来判断"离开了没有" | 在手里；可以碰一开始就在碰的东西 | 同上 |
| pick 的去搬运姿态 | 查（物体挂在手上；搜索时碰撞球放大 `HELD_POSE_MARGIN`） | 查 | 在手里 | 同上 |
| place 的到放下段起点、放下段 | 查（物体挂在手上） | 查 | 支撑面、邻物都是障碍物 | 同上 |
| place 的抽出段 | 查 | 查；刚放下的物体对手指不算障碍物 | 手指可以碰，手臂别的部分不能 | 同上 |
| place 的收臂 | 查 | 查 | 障碍物 | 同上 |
| wipe 等带接触段的接近：自由段（到 S，再到 C） | 查 | 查 | 障碍物 | fallback 直线 |
| wipe 等带接触段的接近：接触段（C → P） | 不查 | — | 可以碰 | — |
| pick 抓空 / 被挡住后竖直离开（`Rig.leave`） | 不查 | 用来判断"离开了没有" | 可以碰一开始就在碰的东西 | — |
| drop 停车点搜索：松手位姿；松手后收臂 | 查（松手前物体挂在手上，之后手空） | 查 | 容器是障碍物 | 这个停车点不要 |

手里有东西时，任何运动都不做目标豁免：手去的是物体要去的地方，那里的托盘、容器都是障碍物。
