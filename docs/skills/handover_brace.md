# handover 和 brace（另一只手接住 / 扶住）

两个都是 pick 的"抓住就停"（`plan_pick(stop="pick_held")`：到达、张手、伸入、合爪、握上的锚点，不抬、不搬）。HAND_PLAN 9i（11-25）。两手一起搬（pick hands=both、bimanual carry）没迁，用户 11-25 定跳过。

## brace（左手扶住）

左手的 pick，捏法只取 rim / rim_rect / top / handle，抓住就停。结果：那只手拿着它，物体没挪过 `TOUCHED_STILL`（1.5 cm）。之后左手 release、收臂。

## handover（右手交左手）

job 是 `skill_jobs/pick.py` 的 `handover_job`，不找停车点（东西在给的那只手里，底盘一动它跟着动）。

1. **目标**：给的手递到胸前的位置（`HANDOVER_AT`，旧代码的 6 个）× 朝向（长物体——最长边超过 `HANDOVER_LONG` 15 cm——转到长轴和正前方成 `HANDOVER_AXIS` 50 / 60 / 70°，两头都行；其他物体 0 / ±90 / 180°）× 接的手的抓法（标注的捏法，加上 `side_variants`：手指水平合拢的顶捏派生两个从侧面水平伸入、手指上下合拢的抓法）。
2. **原地按代价顺序建**：给的手到递出位置的自由段（保持倾角），再在东西的新位置上建接的手的 pick（抓住就停）；第一个建得出来的执行。
3. **碰撞**：接的手规划时，给的手拿着东西、不动：东西是世界里的障碍物（位置从 State 推）；给的那只手（手指、夹爪、相机）在接的手臂的模型里关掉（它贴着自己手里的东西，留着就挡掉所有解），换成底盘环境（`BODY_ENV`）里的小方块——每个碰撞球一个，只有接的手臂、它的手和它手里的东西去查（`Motion._other_hand_boxes`，11-25 规则审查加）。所以离给的手太近的抓法由碰撞检查拒掉；11-25 之前这只手在接的手臂的查询里整个没有，旧代码的 6 cm 间隔删了以后什么都不挡。
4. 接住以后给的手 release（`plan_release`：张开到抓取时的宽度、松手的锚点、沿夹爪轴退出，长度由 `contact_extent` 量）。

检查：P06（11-25）接住、右手松开，整集成功；P07 brace 成功（再跑一次时停车点搜索预算只建了 3 个，没抓成）。
