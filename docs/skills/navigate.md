# 导航与收臂

## navigate（开到一个底盘位姿）

1. **手臂准备。**
   - 空手：右臂[收臂](#收臂)。收不了就留在原处，交给第 4 步的底盘规划器去找地方收。
   - 拿着东西：右臂去[搬运姿态](carry.md)。去不了就保持原样。
2. **左臂收起**：左手空着、又不在收起姿态时，关节空间直线摆过去，会碰就规划；都不行就留在原处。
3. **姿态链**：出发时的姿态 → 收起 → 下垂（空手时两臂垂在身侧；拿着东西时就是当前的搬运姿态，等于没有绕行）→ 到达姿态（默认收起）。
4. **底盘规划**：在 (x, y, 朝向) 格子（5 cm、15°）上搜一条路径，每个位置检查底盘占地不碰家具，并且当时的手臂姿态（两只手臂、躯干、头、手里的物体）不碰场景。只在走不过去的那几段才换成下垂姿态，换姿态都是原地做（`Rig.swing`，两只手臂关节直线插值，规划器按"任何一点移动不超过 2 cm"抽样检查过）。
5. **开过去。** 速度上限按手里的东西定：空手最快；拿着东西 0.25 m/s；拿着碗、杯这类容器，或只有左手拿着东西时 0.17 m/s，加减速 1.8 s。这个上限只写在 `Rig.drive_base` 一处，所有底盘移动（转向、后退、侧移、收臂时挪底盘）都一样。到了再检查一次物体还在手里。

## navigate_place（开到某个地方附近）

navigate 技能（`skill_library`）只有这一条路径（双手搬运除外）；face、retreat、sidestep 也各只有一条路径。

1. **拿着东西时先摆好搬运姿态**，搬运高度抬过目的地台面（`_carry_bottom_z`，W 类，见计划第 7 节）。站位要按开车时的手臂姿态检查，所以先摆好再选站位。
2. **生成站位**：在目标的占地框外 0.45、0.55、0.70、0.85、1.0 m 一圈圈取点（每 15° 一个），朝向目标。去掉底盘占地会碰的（和底盘规划器同一个余量）、离目标太远的；再按行驶姿态检查整个机器人不碰，按离机器人的远近排序。
3. **去掉开不到的**：从机器人现在的位置，在整个场景里算一遍底盘内切圆能走到哪里。
4. **开到剩下的最近那个**（navigate）。失败就失败，不换下一个站位。

## 收臂

**右臂（`tuck`）**：目标是行驶姿态集合 {收起，下垂}。

1. 收起姿态在当前底盘位置不碰东西，就选收起；会碰，就选下垂（手臂垂在身侧）；两个都会碰，就不动（返回"收不了"）。
2. 对选中的姿态做一次关节运动：直线能走就走直线，否则规划；规划不出来就不动。选姿态和这次运动都查手指：手刚松开的物体是障碍物，不查手指会把它扫倒。

需要一定是收起姿态的两处（"原地收起，不行就挪一下底盘再收"、微波炉门轴动作前）不接受下垂。下垂是为 place 准备的：松手后手停在物体上方，收起姿态在这里常常会碰，手伸着时底盘规划器开不出去。

**左臂**：只有一个目标，收起姿态（`_fold_left`，或技能里显式的收左臂）：大臂往后、小臂垂在身侧、手在 0.8 m，整条手臂在底盘柱子以内。直线或规划，都不行就不动。

## 已知问题

- **P07 ×2 收左臂被挡住**：放下一个杯子、再用左手扶稳并松开之后，左臂收不回去。可能是右臂这次收成了下垂姿态，挡住了左臂收起的路径，还没确认。
- **P06 双手交接**：左臂从收起姿态规划到 `handover_left_pre` 出 `GRAPH_FAIL`。
- **原地摆臂擦墙**：T13 no_cup s10 在 `navigate_bookcase_2` 的收起 ↔ 下垂摆臂时右手擦到外墙（PhysX 接触很浅）。见计划第 7 节。
- **放完收不回臂、底盘开不走**：见 [place](place.md) 的已知问题。
