# 导航与收臂

## navigate（开到一个底盘位姿）

1. **手臂准备。**
   - 空手：右臂[收臂](#收臂)。收不了就留在原处，交给第 4 步的底盘规划器去找地方收。
   - 拿着东西：右臂去[搬运姿态](carry.md)。去不了就保持原样。
2. **左臂收起**：左手空着、又不在收起姿态时，关节空间直线摆过去，会碰就规划；都不行就留在原处。
3. **姿态链**：出发时的姿态 → 收起 → 下垂（空手时两臂垂在身侧；拿着东西时就是当前的搬运姿态，等于没有绕行）→ 到达姿态（默认收起）。
4. **底盘规划**：在 (x, y, 朝向) 格子（5 cm、15°）上搜一条路径，每个位置检查底盘占地不碰家具，并且当时的手臂姿态（两只手臂、躯干、头、手里的物体）不碰场景。只在走不过去的那几段才换成下垂姿态，换姿态都是原地做。
5. **开过去。** 拿着东西开慢一些（0.25 m/s；拿着碗、杯这类容器，或只有左手拿着东西时 0.17 m/s，加减速 1.8 s）。这个上限只写在 `Rig.drive_base` 一处，按手里的东西定，所有底盘移动（转向、后退、侧移、收臂时挪底盘）都一样；以前 navigate 和这几个 policy 各传各的速度。到了再检查一次物体还在手里。

## navigate_place（开到某个地方附近）

navigate 技能（`skill_library`）只有这一条路径（双手搬运除外，2026-11-04 起；以前空手、拿着东西分两条，取第一个站位、不查能不能开到）。face、retreat、sidestep 也各只有一条路径，不再按"收好、空手"另走一个 policy。

1. **拿着东西时先摆好搬运姿态**，搬运高度抬过目的地台面（`_carry_bottom_z`，W 类，见计划第 7 节）。这是这次新加的：站位要按开车时的手臂姿态检查。以前先按当时的姿态选站位，开车前 navigate 又换了一次搬运姿态，就会在站位上撞（P15）。
2. **生成站位**：在目标的占地框外 0.45、0.55、0.70、0.85、1.0 m 一圈圈取点（每 15° 一个），朝向目标。去掉底盘占地会碰的（和底盘规划器同一个余量；以前另用 5 cm，房间里 8 cm）、离目标太远的；再按行驶姿态检查整个机器人不碰，按离机器人的远近排序。以前只取前 6 个，现在全部留给下一步。
3. **去掉开不到的**：从机器人现在的位置，在**整个场景**里算一遍底盘内切圆能走到哪里（3b 第 1 项：以前只算起点附近 2 m 的范围，绕门洞才能到的站位被误判为开不到）。
4. **开到剩下的最近那个**（navigate）。失败就失败，不换下一个站位。

## 收臂

**右臂（`tuck`）**：目标是行驶姿态集合 {收起，下垂}。

1. 收起姿态在当前底盘位置不碰东西，就选收起；会碰，就选下垂（手臂垂在身侧）；两个都会碰，就不动（返回"收不了"）。
2. 对选中的姿态做一次关节运动：直线能走就走直线，否则规划；规划不出来就不动。选姿态和这次运动都查手指（11-04 起；以前不查，放完东西收臂时手指扫倒了刚放下的杯子，T04）。

需要一定是收起姿态的两处（"原地收起，不行就挪一下底盘再收"、微波炉门轴动作前）不接受下垂。

这次新加了"下垂"这个选项，因为 place 现在松手后直接收臂。T12 s11 放完小车后，收起姿态在书架边上本身就碰，手又伸在托盘正上方，底盘规划器一步都开不出去。

**左臂**：只有一个目标，收起姿态（`_fold_left`，或技能里显式的收左臂），直线或规划，都不行就不动。没改。
