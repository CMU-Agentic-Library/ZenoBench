# 八个任务的 Skill 规划蓝图

这些是 **VLM 可选用的条件化蓝图**，不是无需观察就固定执行的脚本。每一步在前一步完成后读取新状态，Grounding 决定具体对象和支撑面；缺失候选物时按任务的备选项换绑定。最终始终用 `TaskEvaluator` 检查全部条件。

| 任务 | 典型 Skill 链与条件 |
| --- | --- |
| `collect_fruits` | 若容器不在低书架，先 `004→037` 搬放容器；然后对每个水果 `004→006`；最后检查所有水果确在**同一个**容器、容器在书架、门已关且无掉落。 |
| `tidy_toys` | Grounding 选择存在的玩具箱或储物篮；地面玩具可先 `031` 降躯干，再 `004`，扁平落地物可用 `020`；逐个 `006` 入同一个容器；检查容器直立。 |
| `shelve_books` | 扁平书本可 `035→016→030` 制造悬边、抓取、放上架；若书落地，可 `031→020→005`；书架满时换任务允许的另一个书架支撑面。 |
| `desk_prep` | 笔记本可 `035→016→030`；笔/铅笔 `004→038`；杯/马克杯 `028` 或 `017` 抓取，再 `039` 放到桌面提示点并验证直立。按任务提供的替代物重新绑定。 |
| `breakfast_setup` | 盘/碗、杯/马克杯分别抓取后用 `039` 放到餐桌的共同区域；勺子 `004→038`；将 `max_offset_m` 设为不大于任务 `near.max_dist/2`，最后核对组内两两距离。 |
| `heat_breakfast` | 若食物在冰箱：`003/025` 开冰箱，`004` 取食物；`023→014` 装入微波炉；右手空后关闭冰箱、`024` 关微波炉；`010→040` 启动并达到 60°C；`023→015` 取出，`037` 端到餐桌，再逐门关闭。 |
| `heat_breakfast_preloaded` | 食物已在微波炉且门关时，`010→040`。如果门开先 `024`。参见 [可编译子图](examples/heat_preloaded.skill_subgraph.json)。 |
| `heat_breakfast_combo` | 为“开门检查”先 `023→024`；`010→040` 加热预置燕麦；随后 `003/025→004` 从冰箱取牛奶，`037` 端到餐桌，`007/026` 关冰箱。 |

`closed: all` 要对每个未关的关节选择合适的关闭 Skill；`not_dropped: all` 是全程约束，掉落后须根据最新位置尝试恢复。`near`、`upright`、`heated` 和 `inside` 仍以最终评估器结果为准。当前蓝图证明技能接口能表示这些任务的目标与依赖，并不保证每个候选物在每个随机场景都可达或抓持稳定。
